# SF6 連段練習器

用 Xbox 控制器（或 Hitbox、大搖）練《快打旋風 6》連段的 Windows 小程式：照著畫面上的按鍵一步一步打，打對的會亮起來，整段打完就顯示成功。

## ⬇️ 下載

### [👉 按這裡下載最新版（sf6-combo-trainer.zip）](../../releases/latest/download/sf6-combo-trainer.zip)

下載後「解壓縮」，打開資料夾雙擊 **`SF6ComboTrainer.exe`** 就能用。**不用安裝 Python 或其他東西。**

> 想讓「連段成功」判定更準？可以另外裝遊戲 mod，**不裝也能用**。見下面的「[判定更準：遊戲 mod（可選）](#判定更準遊戲-mod可選)」。

## 功能

- **連段庫**：自己輸入連段，或「從網站抓連段」「從圖片加入」，依角色和標籤整理。
- **練習模式**：像遊戲訓練場的「連段挑戰」，打對的步驟會亮起來並往右淡出，整段打完顯示 Success。
- **指令表**：32 位角色的招式指令（中文），可以自己修改。
- **控制器設定**：支援 Xbox 控制器，以及設成 Xbox（XInput）模式的 Hitbox、大搖；可以自訂每顆鍵、組合鍵。
- **浮動視窗**：一邊玩遊戲一邊看連段，視窗會浮在遊戲上面。
- **快捷鍵**：在遊戲裡也能用快捷鍵（預設 Ctrl+Alt+P 開始練習、Ctrl+Alt+R 重來、Ctrl+Alt+← → 換上一段／下一段、Ctrl+Alt+O 浮動視窗），也能用控制器按住 BACK 加別的鍵。
- **匯出／匯入**：把連段存成檔案分享給朋友。
- **遊戲判定（要裝 mod）**：讀遊戲裡真正的連擊數，連段斷掉、沒打中都會判失敗；也能在連段斷掉時自動幫你重置訓練場。

## 使用前準備

- **電腦**：Windows 10 或 Windows 11。
- **控制器**：Xbox 控制器，或可以切換成 Xbox（XInput）模式的 Hitbox、大搖。
- 不用安裝 Python 或其他程式，下載解壓縮就能用。

## 使用步驟

1. 按最上面的下載連結，下載 `sf6-combo-trainer.zip`（約 100 MB）。
2. 在下載的檔案上按右鍵 →「**解壓縮全部**」→「解壓縮」。（建議放在好找的地方，例如 `D:\` 底下。）
3. 打開解壓縮出來的 `SF6ComboTrainer` 資料夾，雙擊 **`SF6ComboTrainer.exe`**。
   - 如果出現藍色的「Windows 已保護您的電腦」，按「**其他資訊**」→「**仍要執行**」。（這是因為程式沒有付費簽章，不是病毒。）
4. 第一次打開時，練習器會問要不要在桌面建立捷徑，建議按「建立」，之後從桌面打開就好。
5. 到「**控制器**」分頁確認你的控制器按鍵，再到「**連段庫**」新增連段，按「**開始練習**」。
6. （可選）照下面的說明裝遊戲 mod，讓判定更準。

## 判定更準：遊戲 mod（可選）

練習器有兩種判定方式，**兩種都能用**：

| | 不裝 mod（預設） | 裝 mod |
|---|---|---|
| 怎麼判斷成功 | 只看你**按的鍵**對不對、順序對不對 | 按鍵對了，**遊戲裡的連擊數也沒斷**才算成功 |
| 準確度 | 鍵按對就算，就算遊戲裡其實沒連上也會算成功 | 沒打中、打到一半斷掉都會判失敗，最準 |
| 要多裝的東西 | 不用 | REFramework（免費的遊戲 mod 工具），練習器的遊戲內腳本已經附在程式裡 |
| 連段斷了自動重置訓練場 | 只能用「按鍵盤按鍵」的方式 | 可以直接叫遊戲重置 |

### 安裝步驟

**第 1 步：找到遊戲資料夾**

1. 打開 Steam →「收藏庫」。
2. 在「Street Fighter 6」上按右鍵 →「管理」→「瀏覽本機檔案」。
3. 跳出來的資料夾就是**遊戲資料夾**（裡面有 `StreetFighter6.exe`），先不要關。

**第 2 步：下載並安裝 REFramework**

1. 打開 REFramework 的下載頁：**<https://github.com/praydog/REFramework-nightly/releases>**
2. 在最上面那一版的「Assets」底下，按 **`SF6.zip`** 下載。（只要這個，其他遊戲的 zip 不用。）
3. 在 `SF6.zip` 上按右鍵 →「解壓縮全部」。
4. 把解壓縮出來的 **`dinput8.dll`** 複製到第 1 步的遊戲資料夾（跟 `StreetFighter6.exe` 放在一起）。
5. **開一次遊戲**，畫面左上角出現 REFramework 的選單就代表裝好了（按鍵盤的 `Insert` 可以收起或打開這個選單）。
6. **關掉遊戲**。這時遊戲資料夾裡會多一個 `reframework` 資料夾。

**第 3 步：安裝練習器的遊戲內腳本（不用另外下載）**

1. 打開練習器 → 按上方的「**設定**」→ 找到「**遊戲 mod**」那一區。
2. 「遊戲資料夾」通常會自動找到。如果顯示「找不到遊戲資料夾」，按「**選擇資料夾**」，選第 1 步的遊戲資料夾。
3. 按「**安裝遊戲內腳本**」，出現「安裝好了」就完成。
4. 確認「**用遊戲判定連段成功**」有勾（預設就是勾的；沒裝 mod 時會自動改用只比對按鍵）。
5. 下面的狀態應該顯示：`mod：開著 ｜ 遊戲內腳本：已安裝`。

**第 4 步：試試看**

開遊戲進「**訓練模式**」，在練習器選一段連段按「開始練習」照著打。真的連上才會顯示 Success；沒打中或中途斷掉會顯示失敗原因（例如「只打到 3/5 Hit」）。

### 裝好之後可以用的設定（「設定」→「遊戲 mod」）

- **連段斷了就自動重置**：
  - 「遊戲直接重置（預設重置）」：叫遊戲做一般的位置重置（要裝 mod）。
  - 「播放儲存狀態」：重播你在訓練場存下來的狀態（要裝 mod，這個方式還在測試）。
  - 「按鍵盤按鍵」：練習器替你按一下鍵盤上的重置鍵（不用 mod，但要先在遊戲的鍵盤設定裡設好同一顆鍵）。
  - 「失敗後等 N 秒再重置」：想先看清楚哪裡斷掉，可以設 1～2 秒。
- **遊戲啟動時 mod 是開著的，就跳通知提醒我**：避免忘了關 mod 就去打線上。

### ⚠️ 線上對戰前請關掉 mod

- 在「設定」→「遊戲 mod」按「**關閉 mod**」（要先關掉遊戲）。練習器會把 `dinput8.dll` 改名成 `dinput8.dll.off`，檔案不會刪掉，下次開遊戲就不會載入 mod。
- 要練習時按「**開啟 mod**」改回來，重開遊戲就生效。
- mod 開著時，遊戲的**載入畫面**和**配對設定視窗**會出現一張半透明紙卡提醒你。
- 使用 mod 的風險請自行評估。

### 遊戲內腳本做了什麼

- 只在訓練模式讀取雙方的連擊數，寫到 `遊戲資料夾\reframework\data\` 裡的小檔案給練習器讀。
- 你開了「自動重置」時，在訓練模式重置一次。
- 在載入畫面、配對視窗顯示「mod 開著」的提醒紙卡。
- 不改遊戲裡的其他東西，也不會上網。

## 常見問題

**Q：雙擊後出現「Windows 已保護您的電腦」？**
A：按「其他資訊」→「仍要執行」。這是因為程式沒有付費購買數位簽章，Windows 不認得它。

**Q：防毒軟體說有問題、把檔案刪掉了？**
A：打包成 exe 的 Python 程式偶爾會被防毒軟體誤判。可以把練習器資料夾加到防毒軟體的「排除清單」，再重新解壓縮一次。

**Q：控制器沒反應？**
A：到「控制器」分頁看有沒有偵測到。練習器讀的是 Xbox（XInput）訊號：Hitbox、大搖請切換成 Xbox／XInput 模式（切換方法看你的控制器說明書）；鍵盤不能拿來練習打連段。

**Q：不裝 mod 可以用嗎？**
A：可以。不裝 mod 時只比對你按的鍵，鍵按對就算成功。裝了 mod 才會連遊戲裡有沒有真的連上一起判斷。

**Q：按「安裝遊戲內腳本」說「沒有 reframework 資料夾」？**
A：裝好 `dinput8.dll` 後要**先開一次遊戲**，`reframework` 資料夾才會出現。開一次遊戲再關掉，回來再按一次。

**Q：裝了 mod，但練習時沒有用遊戲判定？**
A：照順序檢查：遊戲有沒有開著、是不是在**訓練模式**（其他模式不會判定）、mod 是不是「開著」、腳本是不是「已安裝」、剛裝完腳本有沒有重開遊戲。可以在設定裡按「重新檢查」更新狀態。狀態顯示「需要更新」時，按「更新遊戲內腳本」再重開遊戲。

**Q：遊戲更新後打不開，或 REFramework 選單不見了？**
A：遊戲更新有時會讓舊版 REFramework 不能用。到上面的下載頁下載最新的 `SF6.zip`，用新的 `dinput8.dll` 取代舊的。暫時不想處理的話，先在練習器按「關閉 mod」，練習器會自動改用只比對按鍵。

**Q：想完全移除 mod？**
A：關掉遊戲，到遊戲資料夾自己刪掉 `dinput8.dll`（或 `dinput8.dll.off`、`dinput8.dll.bak`）和 `reframework` 資料夾就好。練習器照樣能用。

**Q：「從網站抓連段」抓不到？**
A：這個功能會連到連段分享網站 sf6cm.sctrip.asia 讀取公開的連段，不用登入。抓不到時請確認網路能打開這個網站；網站改版也可能暫時抓不到。

**Q：關掉視窗後程式還在？**
A：按 ✕ 會縮到右下角的系統匣（時鐘旁邊的小圖示），要完全關掉請在小圖示按右鍵 →「結束」。這個行為可以在「設定」裡改。

**Q：怎麼更新到新版？**
A：先在系統匣把練習器「結束」，下載新版 zip 解壓縮後，**整個資料夾取代舊的**就好。你的連段和設定不在程式資料夾裡，不會不見（見下方「注意事項」）。如果有裝遊戲內腳本，更新後到設定看一下要不要按「更新遊戲內腳本」。

## 注意事項

- **資料存在哪**：你的連段庫、設定、紀錄都存在自己電腦的 `%APPDATA%\SF6ComboTrainer\`（在檔案總管網址列貼上這串按 Enter 就能打開），不在程式資料夾裡，也不會上傳到任何地方。換電腦時可以用「匯出」把連段帶走。
- **會不會上網**：平常不會。只有按「從網站抓連段」時會連到 sf6cm.sctrip.asia 讀取公開的連段，按連段的影片「開啟」時會用瀏覽器打開你貼的影片網址。不會傳送你的任何資料。
- **遊戲 mod**：**線上對戰前請一定要關掉 mod**，使用 mod 的風險請自行評估。
- 字型授權：程式內附的字型都是 SIL Open Font License 1.1，詳見原始碼的 `assets/fonts/` 裡的 LICENSE 檔。
- 本程式是玩家自製的練習工具，與 CAPCOM 無關。《快打旋風 6》（Street Fighter 6）是 CAPCOM 的商標。
